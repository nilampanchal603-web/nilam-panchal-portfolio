## ⚙️ Getting Started

### Clone the repository

```bash
git clone https://github.com/nilampanchal603-web/nilam-panchal-portfolio.git
```

### Navigate to the project folder

```bash
cd nilam-panchal-portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```
